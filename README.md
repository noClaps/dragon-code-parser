# Dragon Code parser

This is a parser for the dragon code specified at the [Dragon Code Memorial Wiki](https://shyriath.a2hosted.com/dragoncode/doku.php). While I'm not as proficient in dragon lore as the author of the wiki, I do find it fun to read about, and I love parsing, so I decided to try and make a parser for the code.

## Build instructions

You'll need [Go](https://go.dev).

Clone the repo:

```bash
git clone https://github.com/noClaps/dragon-code-parser.git
cd dragon-code-parser
```

Run the build script:

```bash
go run .
```

This will place the built output in the `dist/` directory.
